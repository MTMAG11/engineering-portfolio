# Autonomous Rocket Project — Weekly Progress Report

### November 16 – November 22, 2026

## Overview

This week I moved the payload packaging work from planning into CAD. I made four cylindrical tube prototypes that will be printed to test the outer-shell thickness and the outside diameter needed to fit the existing model rocket.

## Payload Tube CAD

I CADed four versions of a cylindrical payload tube. The point of making multiple versions is to compare the shell thickness and outer diameter before committing to one design.

The four models were exported as .3mf files for 3D printing. These are prototypes for the payload that will eventually fly in the model rocket I already have.

I also started working through an idea for a component mounting plate inside the payload tube. I will adjust that design after checking the printed tube dimensions and available space.

The CAD work is complete, but the physical fit-check is not. I have not confirmed that the parts have been printed or tested, so there are no measured fit results yet.

## Simulator

I did not make any confirmed simulator code changes or produce new simulator test results this week. The focus was on the physical payload packaging.

## Next Steps

* Print all four tube variants.
* Compare the outer-shell thickness and outside diameter.
* Check which version fits the existing rocket.
* Use the results to finalize the tube dimensions.
* Revise the component mounting plate around the selected tube.

The next milestone is getting the CAD prototypes printed and checking them against the actual rocket. Until that happens, the tube dimensions and mounting-plate layout are still provisional.
