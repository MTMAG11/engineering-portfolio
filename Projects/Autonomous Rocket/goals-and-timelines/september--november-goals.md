Monthly Goals:

1-Month Goal — By September 30, 2026:
☐ Create and maintain a clean project structure and master roadmap.
☐ Establish the simulation architecture and begin a basic rocket trajectory model.
☐ Get the existing avionics stack to a reliable baseline: BMP388, ICM42688, SD logging, and timestamps.
☐ Continue the transition from Python to C++ through rocket-related exercises rather than isolated tutorials.
☐ Maintain clear engineering documentation and a running list of technical decisions.
☐ End-of-month deliverable: a basic simulation or analysis pipeline that runs end-to-end and produces useful trajectory or sensor data.

2-Month Goal — By October 31, 2026:
☐ Develop a clearer vehicle, environment, motor, sensor, and simulation model.
☐ Create simulated sensor outputs with noise and begin comparing estimated state to true simulated state.
☐ Begin state-estimation work, starting with the mathematical and programming foundations needed for a Kalman filter.
☐ Define a data format usable for both simulation output and real flight logs.
☐ Continue embedded C++ and firmware development using the rocket avionics as the application.
☐ End-of-period deliverable: simulated flight data feeding a basic sensor/state-estimation pipeline.

3-Month Goal — By November 30, 2026:
☐ Implement initial feedback control, starting with attitude stabilization rather than jumping directly to autonomous landing.
☐ Build the beginning of a Monte Carlo test framework for uncertainty, wind, sensor noise, and vehicle variation.
☐ Establish objective metrics for control performance.
☐ Continue validating software against real sensor and hardware behavior.
☐ End-of-period deliverable: a closed-loop simulation where estimated state drives a controller and actuator model, producing measurable control improvement.
