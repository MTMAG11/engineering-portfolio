Week of 9/14 - 9/20:

September 14:
 - Started building the first version of the desktop UI for the rocket simulator using PySide6.
 - Added the initial UI layout with simulation controls, flight view, flight summary, and time slider.
 - Added SimulationConfig as a dataclass to hold the simulator settings instead of passing individual values around.
 - Connected the UI controls for motor, dry mass, gravity, and timestep to SimulationConfig.
 - Added automatic discovery of local .eng motor files in data/motors/, so the motor dropdown now shows all available motors instead of using a hardcoded motor.
 - Cleaned up main_window.py by separating the different parts of the UI into their own methods.
 - Set up the project to run through VS Code's debugger as a Python module instead of launching main_window.py directly.
 - The UI is now connected to the configuration layer, but it does not run the actual simulation yet.
 - Next step is to connect SimulationConfig to simulation.py, return simulation results, and use those results to populate the UI.
 - After V0.1 is working end-to-end, the project structure and file paths will be reorganized, including the motor/engine data paths.
